Acessibilidade

Vigente desde 16 de novembro de 2026

Este site foi feito para ser usado pelo maior número possível de pessoas. A referência usada é o nível AA das Diretrizes de Acessibilidade para Conteúdo Web (WCAG 2.2) e o Modelo de Acessibilidade em Governo Eletrônico (eMAG).

Navegação por teclado

  • Tab avança para o próximo link ou botão, e Shift + Tab volta para o anterior.
  • Enter abre links. Enter ou Espaço acionam botões.
  • O primeiro item da página é o atalho "Pular para o conteúdo", que leva direto ao conteúdo principal.
  • O item em foco recebe um contorno dourado bem visível.
  • No aviso de cookies, depois de feita uma escolha, a tecla Esc fecha o aviso quando ele é reaberto pelo rodapé.

O que mais foi feito

  • Contraste entre texto e fundo pensado para leitura confortável.
  • Títulos organizados em ordem, para facilitar a navegação com leitores de tela.
  • Texto alternativo na foto e rótulos nos menus.
  • Áreas de toque com pelo menos 44 pixels nos links e botões principais.
  • O site se adapta a celulares e pode ser ampliado pelo navegador sem perder conteúdo.
  • Para quem ativou a opção de reduzir movimento no aparelho, as animações são desligadas e todo o conteúdo aparece parado.
  • O idioma da página é declarado como português do Brasil, para os leitores de tela usarem a pronúncia correta.

Limitações conhecidas

O site ainda não passou por uma auditoria completa feita por especialista nem por testes com usuários de tecnologias assistivas. Pode haver pontos a melhorar.

Encontrou alguma barreira?

Se algo no site atrapalhou o seu acesso, escreva para gestor.felipevs@gmail.com dizendo a página, o problema e, se possível, o aparelho e o navegador que você usa. Os relatos são analisados e corrigidos o quanto antes.
